# 外贸单证工作台 TradeDocs

> 本地离线外贸单证工具 · 报价单 / 形式发票 PI / 销售合同 / 商业发票 CI / 装箱单 PL
> **数据 100% 保存在本机浏览器，不上传任何服务器；断网可用；PC 与手机双端。**

> **已融合 TradeKit**：新增 9 种单据（提单 / 原产地证明 / 报关单 / 检验证书 / 熏蒸证书 / 受益人证明 / 发货人委托书 / 保险单 / 成本估算单），全部接入本工作台的数据保存（IndexedDB 客户/产品/条款模板库）、12 种语言、多格式导出与单据联动；并引入明暗主题（顶栏「夜间/白天」切换）。

## 一、这是什么

一套纯前端、零依赖、零构建的外贸单证工作台。打开即用，左侧填表 → 右侧实时预览 → 一键导出 PDF。
从**报价单**一键联动生成 **PI / 合同 / CI / PL**，买卖双方信息与产品明细自动带入，不用重复录入。

## 二、快速开始（1 分钟）

本工作台有三种用法，任选一种（数据都在本机，互相独立）：

| 用法 | 适合谁 | 怎么开 |
| --- | --- | --- |
| 🖥 **桌面 App**（推荐） | 想在电脑上像普通软件一样用 | 双击安装 **`TradeDocs-1.0.0-x64.exe`**，或直接用 **便携版**（免安装） |
| 🌐 **浏览器 + 本地服务** | 不想装任何东西 | 双击 **`start.bat`**，浏览器自动打开 |
| 📱 **手机 / 平板** | 想在手机上开单 | 见下方「手机使用」，装到桌面即可全屏离线用 |

### 方式一：桌面 App（Windows）

- **安装版**：运行 `release/TradeDocs-1.0.0-x64.exe` → 自动创建桌面与开始菜单快捷方式（可改安装目录，卸载不会删你的数据）。
- **便携版**：`release/TradeDocs-1.0.0-便携版.exe`，单文件免安装，放 U 盘里也能跑。

打开后就是独立窗口，有原生菜单（文件 / 编辑 / 视图 / 帮助），`Ctrl+P` 直接调系统打印。

### 方式二：浏览器 + 本地服务

**Windows**：双击项目根目录的 **`start.bat`**，浏览器会自动打开 `http://127.0.0.1:8080/`。

**macOS / Linux / 手动启动**：

```bash
cd 项目目录
node server.mjs          # 默认 8080，被占用会自动顺延到 8081、8082…
# 或（没装 Node.js 时）
python -m http.server 8080 --bind 127.0.0.1
```

然后浏览器访问终端里提示的地址即可。

> ⚠️ **请不要直接双击 `index.html`。**
> 浏览器安全策略（CORS）禁止 `file://` 页面加载 ES 模块，直接双击会白屏；
> 而且 PWA「添加到主屏幕 + 离线打开」在 `file://` 下根本无法实现。
> 用上面的本地服务地址访问才是正确姿势（服务只监听本机，不联网、不写业务数据）。

### 方式三：手机 / 平板

**同 Wi-Fi 访问**：

1. 手机与电脑连同一个 Wi-Fi；
2. 电脑上启动服务后，把地址换成电脑内网 IP，例如 `http://192.168.1.20:8080/`；
3. 手机浏览器打开 → 弹出「装成 App 用」提示条 → 点**立即安装**（或菜单里的「添加到主屏幕」）；
4. 之后桌面就有独立图标，**全屏打开、断网可用**。

**手机端专门的优化**：

- 底部四个大按钮：**编辑 / 预览 / 单据 / 更多**，单手可及；
- 顶部 **5 格单据类型条**（报价单 / 形式发票 / 销售合同 / 商业发票 / 装箱单），带数量角标；
- **输入框字号 16px**——否则 iOS 一聚焦就自动放大整页，很烦；
- 所有可点元素加高到 40px 上下，手指不会点错；
- 适配 iPhone 底部横条安全区，内容不会被遮住。

**技术栈**：原生 HTML + CSS + ES Module JavaScript。运行时无框架、无打包器、无 CDN。
**桌面版**：仅打包环节用 Electron + electron-builder（`npm run dist`），产出的 exe 自带运行时，**用户机不需要装 Node.js**。
**为什么运行时不用 CDN**：离线场景下任何外链都会失效或造成「字体乱码」，所以样式与逻辑全部本地自带。

## 四、数据与隐私

- 所有业务数据存放在浏览器 **IndexedDB**（库名 `tradedocs`），位置在本机磁盘；
- 本地服务只做静态文件分发，**不接收、不存储、不上传任何业务数据**；
- 唯一需要联网的场合：你把静态文件部署到静态托管（仅加载前端资源）；业务数据依然只在本机；
- 清理浏览器缓存/站点数据会清空 IndexedDB → **请定期用「设置 → 导出备份」保存 JSON**。

## 六、授权与激活（导出成品需要）

**免费版**可以建单、填表、预览、多语言、模板库、**备份与恢复**，全部永久免费；
只有「出成品」需要激活：**导出 PDF / 打印（含 Ctrl+P）/ Word / Excel / CSV / HTML**。
免费版没有时间限制，也不会锁住数据 —— 备份随时能导出带走。

**实现方式（离线签名校验，无后端、不联网）**：

- 程序里只嵌入**公钥**（`js/core/license-pubkey.js`），只能验签、无法伪造激活码；
- **私钥只在你手里**（`tools/keygen/private-key.json`），用来给客户发码；`build.files` 已显式排除 `tools/**`，私钥不会进安装包；
- 激活码格式 `TD1.<载荷>.<签名>`，签名算法 RSA-2048 / PKCS#1 v1.5 / SHA-256，**纯 JS 实现**（`js/core/crypto-lite.js`），因此在手机通过局域网访问这种没有 `crypto.subtle` 的环境里也能校验；
- **一码一机**：桌面版取「平台+架构+主机名+CPU 型号+核心数+内存」的哈希作为机器码，重装不变、换机才变；
- 授权状态存本机，但**每次启动重新验签** —— 改数据库里的标记没有任何用。

发码、换机、密钥保管、策略调整、能力边界等细节见 **[docs/激活码说明.md](docs/激活码说明.md)**（这份别发给客户）。
